# الاختبارات

اختبارات فعلية تعمل بلا إنترنت وبلا أي خدمة خارجية: مصدر HLS وهمي محلي
+ محاكي لقواعد `.htaccess` على خادم PHP المدمج.

> هذا المجلد ممنوع من الفتح عبر الويب في `.htaccess` و `nginx.conf.example`.
> يمكنك حذفه قبل الرفع إن أردت — لا شيء في التشغيل يعتمد عليه.

---

## التشغيل

```bash
php tests/run-tests.php          # الحالات العشرون كاملة (يشغّل خوادمه بنفسه)
php tests/test-viewers.php file  # مخزن الإحصاء: file | sqlite | redis | apcu
php tests/test-worker.php        # يتطلب dev-serve يعمل أولًا
```

للتجربة اليدوية:

```bash
php tests/dev-serve.php start    # مصدر 8801 + بروكسي 8802
curl -A "MTX Player" http://127.0.0.1:8802/api/token/10
php tests/dev-serve.php stop
```

## الملفات

| الملف | الوظيفة |
|---|---|
| `origin.php` | مصدر HLS وهمي يعدّ كل طلب فعلي وصل إليه |
| `router.php` | يطبّق ترتيب قواعد `.htaccess` نفسه على خادم PHP المدمج |
| `run-tests.php` | الحالات العشرون + الحماية + القياسات |
| `test-viewers.php` | مخازن الإحصاء الأربعة وتحديد معدّل الكتابة |
| `test-worker.php` | إثبات التحميل المسبق في وضع worker |
| `dev-serve.php` | تشغيل/إيقاف خوادم التجربة |

### قنوات المصدر الوهمي

| القناة | ما تحاكيه |
|---|---|
| 10 / 20 / 30 | بث TS عادي (نافذة 6 مقاطع، مقطع كل ثانيتين) |
| 66 | روابط مقاطع بتوكن مصدر طويل جدًا (650+ حرفًا) |
| 77 | Master Playlist بقائمتين داخليتين |
| 88 | fMP4 مع `#EXT-X-MAP` ومقاطع `.m4s` |
| 99 | مشفّرة بـ `#EXT-X-KEY` |

### حقن الأعطال

```bash
curl "http://127.0.0.1:8801/control?fail=10"     # تعطيل القوائم 10 ثوانٍ
curl "http://127.0.0.1:8801/control?variant=b"   # تبديل المصدر + رجوع التسلسل
curl "http://127.0.0.1:8801/control?variant=a"   # عودة
curl "http://127.0.0.1:8801/control?reset=1"     # تصفير العدّادات
curl "http://127.0.0.1:8801/control"             # قراءة العدّادات
```

## ملاحظة عن خادم PHP المدمج

يُستخدم للاختبار فقط، ويعمل بـ `PHP_CLI_SERVER_WORKERS=24`. هو **أبطأ
بكثير** من Apache/PHP-FPM، لذلك أرقام زمن الاستجابة هنا حد أدنى متشائم.

`router.php` يرسل المقاطع الثابتة بنفسه (بدل `return false`) لأن الخادم
المدمج يحدّد الملف عند بداية الطلب، فلو أُنشئ المقطع بعدها بأجزاء من
الثانية أعاد 404 وهميًا لا وجود له في Apache. عدّاد `static` مقابل `php`
يبقى دليلًا صحيحًا على أن `index.php` لم يعمل.
